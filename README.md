# Niel Angelo Rico Doyugan - Front-End Developer Portfolio

A modern, responsive, and visually engaging personal portfolio website built with **HTML5**, **CSS3**, and **Vanilla JavaScript**. Designed to showcase featured projects, technical skills, and experience with smooth animations and interactive UI elements.

---

## ✨ Features

- **Particle Hero Canvas**: Interactive dynamic particle network background in the hero section.
- **Dynamic Typing Effect**: Rotating headline titles showcasing developer roles.
- **Interactive Custom Cursor**: Fluid trailing cursor dot and ring with hover states.
- **Scroll Reveal Animations**: Smooth reveal-on-scroll animations using the Intersection Observer API.
- **Interactive Tech Stack**: Filterable tabbed skills display with animated progress bars.
- **Fully Responsive**: Optimized for all screen sizes (mobile, tablet, desktop) with a mobile navigation drawer.
- **Zero Heavy Dependencies**: Pure vanilla web stack for instant load times and optimal performance.

---

## 🛠️ Built With

- **HTML5**: Semantic and accessible markup.
- **CSS3**: Custom design system, CSS variables, glassmorphism effects, flexbox & grid layouts.
- **Vanilla JavaScript (ES6+)**: Custom animations, canvas rendering, form validation, and event handling.
- **Google Fonts**: [Outfit](https://fonts.google.com/specimen/Outfit) & [Inter](https://fonts.google.com/specimen/Inter).

## 🚀 Getting Started

No build step or external package installation is required to run this project.

### Method 1: Open Directly in Browser (Easiest)

Simply open the `index.html` file in any modern web browser:

- **Windows PowerShell**:
  ```powershell
  Start-Process index.html
  ```
- Or double-click `index.html` in your file explorer.

### Method 2: Run with a Local Web Server

Running through a local web server is recommended for the best experience (asset loading and local routing).

#### Option A: Using Node.js (`npx serve`)
```bash
npx serve .
```

#### Option B: Using Python
```bash
# Python 3
python -m http.server 3000
```
Then navigate to `http://localhost:3000` in your browser.
